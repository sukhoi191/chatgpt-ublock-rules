# ChatGPT UI Cleanup for uBlock Origin

A small uBlock Origin filter list that removes unwanted ChatGPT UI elements such as follow-up suggestions, duplicated follow-ups, reaction clutter, rating prompts, and related leftover spacing.

## Usage

Import the filters into **uBlock Origin → My filters**, then apply changes.

## Notes

- Intended for `chatgpt.com`
- Filters may need updates when ChatGPT's frontend markup changes
